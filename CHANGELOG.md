# Changelog

Notable changes to this project are recorded here, newest first.

## 1.0.2

- Corrected the README that ships in the release ZIP: requirements, Setup behavior for unusual launch options, uninstall, error file names, what the optional debugger records, how to add the debug tools back, the signed-tag example and the issue link.
- The release ZIP now also includes `CHANGELOG.md`, `LICENSE.md` and `REUSE.toml`.
- The helper and Setup are unchanged.

## 1.0.1 - 2026-08-17

- Initial public release: free mouse movement across monitors, clean handoff to and from the game, a single-click return, an in-game cursor over exposed parts of the game, silent start through Steam, and an optional observation-only debugger.
