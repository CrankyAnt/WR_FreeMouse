# Publication Policy

**Repository visibility:** public

**Tracked or shared surfaces:** repository files (source, README, `docs/`, `.gitattributes`, `.gitignore`); GitHub Issues and pull requests

**Local-only surface:** `.docs/`

Treat tracked files and tracker content as potentially public. Publish professional, evidence-based conclusions without private deliberation, personal judgments, or unnecessary person-sensitive context. Show exact wording for approval when it could materially affect a person or organisation.

Local-only files may preserve fuller internal reasoning, but never secrets, credentials, or sensitive personal data.
