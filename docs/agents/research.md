# Research Artifacts

**Durable artifact location:** `.docs/research/`

Durable research artifacts follow `docs/agents/delivery.md`. The invoking workflow owns publication through its recorded delivery path and publish boundary. A planning-map research ticket without its own override inherits the repository delivery strategy. Apply an unambiguous direct-main exception autonomously; ask only when the applicable strategy genuinely cannot be determined.

`research-evidence` uses three output modes:

- `inline` returns evidence to the invoking workflow and creates no file.
- `artifact` writes durable Markdown and returns its path plus a summary.
- `both` writes the artifact and returns a compact usable result; this is the default for planning-map research tickets.
